# FREELAS

DIREÇÃO VISUAL

Adotar padrão premium inspirado em Figma, Behance e produtos digitais contemporâneos:

- layout limpo e sofisticado;

- grid consistente;

- bastante respiro;

- cards bem definidos;

- hierarquia visual forte;

- microinterações suaves;

- sombras discretas;

- bordas arredondadas moderadas;

- responsividade integral;

- aparência de produto digital finalizado.

TIPOGRAFIA

Principal:

Inter

Alternativas compatíveis:

DM Sans

Manrope

Plus Jakarta Sans

Sugestão:

- Títulos: Manrope ou Plus Jakarta Sans, peso 600–700

- Interface, formulários e dashboards: Inter, peso 400–600

- Textos institucionais: DM Sans, peso 400–500

Evitar misturar mais de duas famílias tipográficas na mesma experiência.

Objetivo:

visual moderno, profissional, elegante, altamente legível e coerente entre Landing, Contratante, Cooperado e Admin.
